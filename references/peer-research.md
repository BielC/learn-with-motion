# Peer skill research

Reviewed on 2026-11-03 to improve this skill's explanatory craft and production reliability. Discovery used the Skills CLI and GitHub search, followed by selected source-file inspection at the revisions below. This is not an end-to-end benchmark of these tools or independent evidence of learning effectiveness. Some large collections were read selectively. Stars and install counts did not determine adoption.

## Changes made from this comparison

1. **Check the interpretation of important diagrams.** Alongside the question, claim and visual evidence, consider the plausible wrong reading and whether schematic details could mislead. For a retry, the picture should distinguish a lost reply from a failed operation. This extends the existing review rather than adding another form.
2. **Resolve optional named speech landmarks.** A unique script phrase becomes an estimated local start/end time. Missing or ambiguous phrases fail before synthesis; scene references must fail before rendering rather than silently appearing at time zero. This uses the existing paragraph voice, ASR and renderer. It does not add a Manim dependency or claim exact word timing.
3. **Split speech from alignment caching.** Inspection of our helper found ASR settings and cue position in the speech identity. Changing the ASR prompt or inserting a cue could regenerate unchanged narration. Speech now depends on exact text and synthesis settings, with a position-independent seed. Alignment depends on that speech, its audio hash and ASR settings. Editing bookmarks reuses both caches. This is an implementation correction informed by the timing/cache comparison, not code borrowed from a peer.

The concrete mechanics have 16 passing offline helper/package tests, including cache invalidation, reorder stability, phrase resolution and invalid timing. A local Qwen smoke test generated 24.64 seconds of synthetic narration. Changing its ASR prompt rebuilt timing while preserving the WAV's hash and modification time; repeat runs, bookmark edits and inserted/renamed cues reused speech and alignment. These checks establish software behavior, not improved attention, teaching quality or preferred voice delivery. A new topic and learner feedback are still needed to assess those outcomes.

## Scope and reuse

The comparison synthesizes ideas in original prose. No third-party code, prompts, voices, models or media were copied into this package. Most inspected repositories reported MIT licensing in GitHub metadata. License metadata for `gqy20/manim-agent` and `remotion-dev/skills` was inconclusive during this review, so no reuse permission is assumed. Check actual licenses before any future copying. Linked repositories and files may change; the links above pin the inspected revisions.

Keep this note as research provenance. It need not be loaded for ordinary lesson production; the actionable changes live in [film-direction.md](film-direction.md) and [narration.md](narration.md).
