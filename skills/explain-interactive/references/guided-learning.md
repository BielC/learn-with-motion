# Optional guided use

Read only when the learner asks to work through the explanation together. Keep a completed page available if they requested one; conversational guidance is not a delivery gate.

1. Restore the actual subject, the current example and the question being explored. Explain the prerequisite needed for that connection before asking the learner to reason about it. Keep one current representation rather than simultaneous map, code, table and animation panels.
2. At an agreed boundary, ask one useful prediction or explanation about a consequence, design choice or changed condition. Wait for the answer before revealing the solution. Honor a request for no quizzes and use a worked trace instead. Do not require arithmetic unless it clarifies this connection.
3. Read the reasoning rather than grading words or clicks. Affirm only what is sound. Separate what an actor knows from what is true or still unknown. If a link is missing, restore a smaller example, intermediate state or prerequisite, then connect it back to the actual subject. If the reasoning is already clear, advance instead of repeating tests.
4. When the learner loses the thread, stop adding concepts. Restore the last shared state and isolate one uncertain connection. Avoid repeating the same paragraph more slowly or asking them to diagnose the entire gap. Shrink the next step or offer a clean stopping point if they report fatigue.
5. At a pause, leave a short checkpoint with the subject, example state and next unresolved connection. On return, restore it instead of automatically replaying the overview. Keep this in the conversation or requested artifact; do not create a learning dossier, memory entry or reminder.

When useful and welcome, a later changed condition or short explanation without the worked answer can provide evidence beyond assisted tracing. Distinguish that evidence from confidence and recognition. There is no required quiz count, mastery score or scheduled follow-up. Treat the value of this method as something to assess with the learner.
